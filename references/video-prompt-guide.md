# AI 图像与视频提示词指南

## 1. 总原则

- 提示词负责模型无法从素材直接得到的关系：谁是谁、位于哪里、为什么行动、按什么顺序变化、镜头从哪里到哪里。
- 自然语言优先。删掉无作用的“8K、最佳画质、电影级”等堆叠词，保留能改变结果的具体信息。
- 真实感来自关系与因果：人物与环境接触、动作重量、视线落点、道具反应、前景遮挡、生活痕迹和光线来源。
- 图像提示词描述“最终能看见什么”；视频提示词描述“什么随时间改变”。
- JSON 可用于整理需求和让大模型规划，但不是提升生成质量的魔法格式。最终按目标模型偏好的自然语言输出。

## 2. 写之前先做四件事

1. 明确用途、平台、时长、画幅、生成模式和必须保留的文字/Logo。
2. 给素材分工。单个素材只承担一个主要控制变量，减少角色、风格、构图互相争夺。
3. 建立全局锁：人物身份、服装、产品结构、场景方向、色彩、摄影规律、声音。
4. 对复杂空间、多人、打斗或长镜头，补俯视调度图、箭头标注、深度图、法线图或轮廓图。文字描述意图，条件图约束结构。

### 2.1 剧本先转成可见节拍

拿到剧本后，不要直接逐句扩写提示词。先对每个剧情单元回答：

- `WHAT`：观众必须看见谁、什么物件、什么动作或结果？
- `WHY`：这一拍承担什么叙事职责——交代信息、推进动作、建立空间、呈现反应、完成转折还是调节节奏？
- `HOW`：用什么景别、机位、表演、声音和时长把它拍清楚？

随后把该单元写成“起始状态 → 外部触发 → 可见变化 → 结束状态”。抽象词必须落到可见证据：不要只写“关系疏远”，要写谁避开视线、身体与谁拉开距离、哪个动作没有得到回应，以及镜头最终停在哪个结果上。

### 2.2 资产覆盖审查

在设计镜头前，先检查每个剧情节拍需要哪些人物、服装、场景、道具、构图、动作、声音和连续性依据。为每项资产标记状态：

- `可直接使用`：清晰、版本正确，能承担指定控制职责。
- `缺视角`：身份或结构可用，但缺正侧背、远近景或空间反向依据。
- `缺状态`：缺剧情所需的服装、表情、损伤、道具持有或环境变化状态。
- `需重做`：质量、身份、结构或版权来源不能支持成片。
- `仅供参考`：只提供色彩、构图、动作或氛围，不允许控制身份与结构。

资产不足时先改镜头设计或补最小必要资产，不要用提示词假装参考图已经提供了不存在的信息。一个素材仍只承担一个主要控制职责。

同时检查资产的“状态所有权”：同一实体道具在一个镜头中只能有一个持有者、位置和状态。若外套被脱下放在椅子上，人物就不能同时穿着它；若道具需要分别展示，将其做成独立资产并标明哪一拍中启用。

## 3. 图像提示词模板

先用“时间、主体、场景、风格”检查是否遗漏决定画面的信息。这四项是检查清单，不是必须填满的格式；参考图已经锁定的内容不要重复改写。

```text
用途与画幅：……
主体：人物/产品身份、外形结构、妆造与当前状态……
环境：前景……；中景……；背景……；主体与环境的接触关系……
构图与摄影：主体位置、景别、机位高低与角度、焦段、拍摄距离、景深……
光线：物理光源、方向、软硬、明暗比、色温、光线落在哪些表面……
色彩：主色、辅助色、少量点缀色及大致比例……
叙事痕迹：刚刚发生了什么、即将发生什么，画面中留下哪些可见线索……
限制：只写当前任务真正需要禁止的变化……
```

构图至少确定主体位置、视觉引导、前中后景和留白。35mm 常用于环境叙事，50mm 接近自然观察，85mm 适合人物与商业特写；广角贴脸会夸张五官，应有明确意图才使用。

## 4. 视频提示词模板

先用“主体、动作、效果、节奏”检查：观众看谁、发生什么变化、怎样看到和听到、变化何时发生。效果包括运镜、稳定性、焦点、环境、速度和声音；只选择本片段真正需要的效果。

### 全能参考/图生视频

```text
参考映射：@图片1锁定角色脸、发型和服装；@图片2锁定场景空间；@图片3仅参考色彩与光线……
全局：画幅、时长、视觉基调；人物/产品/场景保持一致；摄影机与声音的整体规则……
起始状态：人物、道具、环境和摄影机在第一秒的位置与状态……
触发：什么事件促使人物或环境开始变化……
动作状态流：起始状态 → 触发 → 主体反应 → 身体/服装/道具/环境的次级反应 → 收束状态……
摄影机：起始机位、景别、焦段、运动路径、速度、前景遮挡与视差、结束构图……
时间轴：0–X秒……；X–Y秒……；Y–Z秒……
演员表演与动作状态流：人物当下目标；触发后眼睛、头部、肩膀、呼吸、重心和手脚如何依次响应；与谁交互；情绪如何变化并收住……
光线、环境与空间反应：物理光源、方向、软硬、色温和衰减；前中后景；人流与生活痕迹；风、衣物、树叶、道具、影子和接触面的反应……
声音：对白/呼吸/动作音/环境音/音乐在相应节点的变化……
结束状态：为本镜头收束或下一镜头衔接保留的姿态、方向、速度和构图……
限制：不新增人物；不改脸和服装；不重绘准确文字；不发生无关镜头切换……
```

### 文生视频

先写统一摄影母版，再写单镜头。场景没有参考图时，要具体规定空间层次、尺度、材质、主色如何进入人物/建筑/地面/空气、主光方向、焦段倾向和肤色表现。

### 首尾帧

只在需要精确端点转化时使用：明确首帧哪些元素保持、变化的触发与路径、变化传播顺序、尾帧必须对齐的结构。长视频不要把每段尾帧机械当作下一段首帧；优先让下一段继承视频中的方向、速度、动作阶段和声音状态。

## 5. 人物与表演

- 用角色编号或参考图锁定身份；脸、身体、服装和剧情状态可拆成独立资产。
- 原创角色从脸型、骨骼比例、五官间距、皮肤特征和气质组合，不照搬一张完整真人脸。
- 让人物“有事可做”：道具和环境提供行动动机，动作之间有前因后果。
- 写状态流，不写孤立动作清单。身体动作包含重心、肩胯、手臂、头发和衣物的联动。
- 摄影机指令与演员指令分开检查。摄影机移动不能替代演员表演；“近景、慢推、特写”不能说明人物该如何演。
- 表演指令从人物目标开始：他此刻想完成什么、在防备什么、想向谁隐藏什么。随后写触发、注意力转移、身体响应、主动作、次级反应与情绪收束。
- 不只写“皱眉、微笑、紧张”。例如写成“听见关键词后眼睛先停住，呼吸短暂停顿，下颌收紧半拍，想回应但把视线移回道具”，让情绪落在可见行为上。
- 多人反应错开半拍或由前一人的动作触发后一人。只有剧情明确要求时才让多人同步转头、起跑、微笑或惊讶。
- 轻喜剧表演优先使用一本正经的执行、失败后的停顿、延迟反应、想反驳却收住、旁观者压住笑意等关系；不依赖夸张鬼脸和无来源音效。
- 情绪戏用克制、迟疑、呼吸、视线、停顿和替代动作表达。不要让眉眼嘴手同时直白表演同一种情绪。
- 多角色按空间或时间拆开指令，明确每人的站位、方向、目标和交互对象。
- 群戏先写开场站位，再写谁可以移动、移动到哪里、谁必须留在原地，以及位移在哪个时间点结束。后续对白段保持位置稳定，避免持续漂移。
- 接触、拉开、阻挡、递交或接住等动作写成交接链：前一动作成立后，后一角色才接手；明确松手时机，避免复制肢体、多人同时抓握或道具突然换手。
- 站位图或俯视图只作调度参考时，明确“不是首帧、不得进入成片、不得控制人物外貌与画风”。
- 语音写年龄感、音色质地、语速、节奏、停顿、呼吸、重音和情绪转折。
- 对白写清说话对象、实际距离和收音关系；切到特写不等于人物空间距离改变。音频参考默认只锁音色，不复用原音频台词。
- 凡有台词，完整提示词逐字写出台词，并标明自然开始时间、停顿、重音、音量、画外音/现场对白、口型要求和听者反应。不能用“按原句说”“准确说”替代，也不能要求生成时回看表格其他列。

### 姿态锚点、动作预算与误读检查

- 高风险动作开始前先给一个可见的基础姿态锚点：人物直立或坐着、胸口朝向、双脚如何承重、手和道具位于哪里。不要只写“准备、警觉、谨慎、紧张”，让模型自行选择姿势。
- 每个短节拍只安排一个主动作，最多附带一个由它直接引起的次级反应。若同一节拍还要停车、下车、交接、扫码、转身和离开，应增加时长或拆成多个镜头。
- 触发必须先于反应。目标尚未出现时，不让人物提前进入捕猎、攻击、逃跑或庆祝姿态；写清动作何时开始以及最终停在哪个姿态。
- 多人物或不同物种分别写姿态和动作，不把一方的身体语言紧邻另一方而省略主语。尤其要避免把动物的前倾、低身、碎步或颈部动作迁移给人类角色。
- 道具动作写可见轨迹、接触点、受力与收束，不用抽象的解剖学口令堆叠代替运动。例如写网圈从身体右后侧沿单一斜上弧线掠过，挥空后网袋受重力下垂、人物向前一步缓冲并停住。
- 完稿后连读相邻动作词，检查组合语义。诸如“压低重心 + 放轻脚步 + 颈部前伸 + 缓慢接近 + 屏息”会共同形成潜行或伏击，即使每个词单独合理。先用正向姿态说明实际要演什么，再加入一两条针对当前误读的限制。

推荐的演员动作小模板：

```text
人物目标：……
基础姿态：躯干、双脚、视线、双手和道具的初始状态……
外部触发：……先发生。
动作状态流：眼睛/头部先响应 → 一个主动作 → 道具、衣物或环境的次级反应 → 明确停止姿态。
角色隔离：其他人物或物种分别保持什么姿态、何时才行动……
当前风险限制：只禁止已经出现或高度可能出现的误读……
```

## 6. 摄影、光线与色彩

- 镜头是坐标原点。写清机位高低、平视/俯视/仰视、景别、焦段、距离、运动和首尾构图。
- 复杂运镜使用可执行路径：从哪里开始，沿哪个方向移动，何时绕行或升降，最终停在哪里。
- 大透视来自近大远小、Z轴纵深、前景遮挡和运动视差，不来自“空间感强”四个字。
- 光线写物理来源、方向、软硬、色温、衰减和受光表面。氛围应由这些关系产生。
- 一组镜头先建立固定色卡与摄影基准，生成中重复使用，生成后再统一校色。
- 高色彩密度画面让主色进入人物、场景、光线和空气，同时用明度、材质、冷暖和空间深浅保持层次。
- 每个场景写物理光源，而不是只写“电影感、暖色调”：光从哪边、何种高度进入，直射或经过树叶/窗户，人物与道具哪些表面受光，阴影落向哪里，进入室内或树荫后如何衰减。
- 环境至少建立前景遮挡、中景行动、背景空间或生活活动。居民、游客、车辆和店主继续自己的目标，不因主角出现而全部停下或围观。
- 环境必须对行动产生反应：脚接触地面、网袋受重力和空气阻力、车轮影移动、树叶受局部气流、衣摆在停步后保留惯性、局部特效在邻近表面形成有限反光。
- 魔法光默认只是局部辅光，除非剧情要求改变环境。写清影响半径、受光表面、亮度变化与消退，避免整场无来源发亮或改变固定色温。

### 6.1 功能性色板与场景预上色

色彩是叙事要素、多场景需要统一或视频模型容易继承参考图跳色时，不只写一组颜色值，而是建立功能性色板。

1. 从 3–4 张同一作品、相近调性的画面取色；参考中同时包含人物、环境和可见光源，不只用人物近景。
2. 为每个颜色写名称和职责：环境主色用于最大面积，阴影色用于暗部和深处，光源色用于灯具、窗口及受光表面，辅助色区分材质和空间层次，强调色只出现在少数视觉焦点。
3. 验收色板：颜色是否在参考中反复出现，是否占据主要面积，是否表示真实光源、阴影、主体或必要强调。删除只因“好看”但在参考中几乎不存在的颜色。
4. 先用无人场景资产锁定建筑结构、物件数量、位置和透视，再按功能色板调整材质色与光色。视频会强继承关键帧色彩时，优先把色彩关系做进场景图，不只在视频提示词中补写。
5. 预上色只改颜色与光色关系，不改结构、布局、物件数量、位置和透视；保留原色板的明度、饱和度和冷暖层级，色板本身不得出现在成片里。
6. 肤色保持自然。消防箱、灭火器、出口、交通与警示标识等功能色保留真实颜色，不向周围材质溢色。
7. 所有颜色依附真实材质或物理光源，不用全画面单色覆盖、抬黑位或过饱和滤镜假装风格统一。

角色定妆图中的中性灰背景、柔和三点布光只用于读取身份与材质，不作为成片光线依据。入景后重新按场景物理光源生成人物光影，保留接触阴影、遮挡阴影和环境反光，避免人物像贴在背景上。

分别生成的“调色前/后”版本只能评估总体方向；如果摄影机、动作或随机种子不同，不声称它们是逐帧可归因的对照。

## 7. 故事、分镜与长视频

- 一个点子先回答：人物想要什么、什么阻碍他、失败代价是什么。再决定情绪、反转和可拍动作。
- 先做故事板。用全景建立空间，中近景推进表演，特写强调线索；空镜、插入镜头和环境反应调节节奏。
- 长视频先建立可复用资产：人物正侧背与不同状态、服装、场景锚点与空间地图、产品多视角、声音测试、固定色卡。
- 每个镜头只承担一个主要叙事任务，并记录上一镜头的结束方向、速度、视线、道具与声音状态。
- 轻喜剧常用“慢状态建立 → 集中反应 → 突然加速或反差收束”；笑点优先来自角色目标受阻、反应停顿、物种或音色反差和环境余波，不依赖夸张鬼脸。
- 巨物镜头按“环境异常 → 局部揭露 → 尺度参照升级 → 完整展示 → 力量释放”推进。用人物、建筑、山峰、云层等参照和环境反馈证明体量，不把巨物简单塞满画面。
- 品牌短片从真实产品功能提炼可见的变化，让产品触发人物、环境或秩序的改变；特效必须服务产品记忆点。
- 创意开场应在前几秒制造需要确认的信息，可用非常规入画、动态遮罩或镜头形态展开，但要与主题有关。

### 7.1 镜头覆盖包

围绕一个事件，从下列覆盖类型中选择真正需要的镜头，不固定数量：

- 环境：时间、地点、尺度、方向和人物所处关系。
- 主体：主要动作或对白成立的核心镜头。
- 细节：关键道具、手部、线索、材质或动作接触点。
- 反应：动作对他人、主体自身或环境造成的可见影响。
- 结果：事件完成后的新状态，负责收束或承接下一拍。
- 主观视角/视线落点：说明人物看见了什么。
- 空间关系：交代谁在谁的哪一侧、距离和移动路径。
- 备用插入：在主动作不可用时补信息、压缩时间或隐藏跳切。

“环境、主体、细节”是最低限度的覆盖思维，不是所有事件都必须机械生成三镜。为每个候选镜头写一句职责；不能说明它补足什么的镜头通常可以删除。

### 7.2 剪切动机与匹配依据

设计镜头时同时设计它为什么能接到前后镜头。优先选择一种主连接依据，必要时增加一种辅助依据：

| 连接依据 | 需要保持或交接的内容 |
|---|---|
| 动作阶段 | 在动作准备、发力、接触或结果的明确节点切换，不重复或跳过关键阶段 |
| 视线/主观视角 | 先建立人物视线，再交代视线落点；方向和高度应可对应 |
| 方向与速度 | 主体或摄影机的运动轴向、速度趋势和能量连续或有意反转 |
| 形状/构图/颜色 | 主体位置、轮廓、明暗块或色彩焦点形成视觉接力 |
| 主体焦点 | 前镜头的注意力落点成为后镜头的主要对象 |
| 声音 | 对白、环境声或动作声先入、延续或在明确节点收住 |
| 新信息/反应/空间补充 | 后镜头回答前镜头提出的问题，或显示动作造成的影响 |

剪切动机不是“为了好看”。它应说明此处为何必须换镜，以及换镜后观众获得了什么。需要备选素材时，主动生成同一动作节点、方向、速度或视线关系可匹配的版本。

### 7.3 缺口诊断与补镜头

发现段落不清楚或难以连接时，先判断缺口属于哪一类：信息、动作阶段、空间关系、人物反应、道具细节、转场、事件结果或节奏。然后只补能解决该缺口的最小镜头或资产。

- 信息不清：补关键对象或线索特写。
- 动作跳跃：补准备、接触或结果阶段，不要把整段动作重做。
- 空间混乱：补环境建立、双人关系或移动方向镜头。
- 情绪无落点：补由具体事件触发的反应与收束。
- 跳切明显：用有叙事价值的细节、环境反应或主观视角遮接。
- 节奏松散：调整镜头进入/离开节点，必要时再补短镜头；不默认加入故障、漏光等效果。

### 7.4 角色展示 PV 的能量结构

角色展示、广告或 MV 需要明显能量起伏时，先设计演出，再写生成提示词。

- 角色外形先确定少数可识别特征：发型轮廓、服装大形、一处关键饰件或独特神态。装饰集中在重点区域，其他区域保留完整大色面和可读轮廓。
- 迭代角色时一次只修最影响观感的问题，同时明确必须保留的脸、发型、配色和轮廓。
- 角色参考板验收同一张脸、同一套服装、同一身体比例和同一材质风格；参考未展示的背面可以合理补足，但要检查剪裁、材质和连接是否自洽。
- PV 方案先确认开场钩子、角色如何展示性格与能力、唯一主高潮、高潮后的情绪回收和最终落板。普通镜头每次换镜都应提供新信息；不为固定镜头数量凑数。
- 只设置一处明显的速度、亮度或能力释放高潮，其余镜头用动作、视线和新信息推进；高潮后逐层减少动态并稳定落板。
- 表情与正在发生的动作同步，不停下来摆出孤立表情。优先写视线先变、头部跟随，再让眉眼、嘴角和重心回应具体事件。
- 多段生成的每段提示词都独立完整。跨段象征物重复写清形状、尺寸、位置、朝向、材质、内部结构和光色，不写“沿用上段”。

### 7.5 一镜到底与终点构图锁定

一镜到底不是普通视频的默认方案。当用户需要连续空间路线、名画动态化或精确回到指定尾帧时再使用。

- 先判断素材是否支持长镜头：有可发展的人物/动物关系，前中后景层次，能容纳摄影机的道路或空间通道，以及风、光、水、云、灯火等可动态元素。
- 把摄影机路线画成一条连续空间轨迹：起点、通道、跟随对象、转向依据、升降与速度变化、终点。不把几个独立镜头用遮挡或甩镜伪装成连续运动。
- 前景遮挡用来强化视差、交代速度或完成有动机的空间交接；遮挡不得长时间盖住主体或隐藏路线断裂。
- 环境运动共用同一物理系统：风向、光线、衣物、发丝、植物、水面和道具反应不互相矛盾。
- 需回到原画或指定关键帧时，把终点机位、景别、人物与道具位置、主要轮廓、明暗块和边缘留白写成可验收锁。结尾先完成精确对齐，再让运动逐层减弱，最后稳定保持约 2 秒。
- 验收连续性、路线目的、前景有效性、风光与物体运动统一性、终点构图精度。“写实开始、油画结束”只是一种可选创意，不写成默认模板。

## 8. 声音设计

先读懂画面和剪辑节奏，再设计音乐结构。逐镜头列出动作声、环境声、材质声、转场声、对白和呼吸，标注发生时间、远近、强弱与空间位置。音乐跟随情绪弧线，不要用一首无变化的背景乐覆盖全部事件。

画外声音可以先于主体出现并触发人物反应：声音发生 → 眼睛先寻找 → 头部跟随 → 肩膀和重心响应。画外主体不应因此被自动生成进画面。需要跨镜衔接时，可让环境声或对白短暂先入或延续，但要标明距离和方向。

声音按职责区分为环境氛围、动作拟声、转场/强调、对白/呼吸和音乐。为重要声音写明入点、出点、远近、强弱及它服务的动作或情绪，不按素材文件名选声音。段落级音乐状态可设为继续、停止、换质感、留白或短音效强调；变化应发生在剧情转折、停顿或能量改变处。

快切仅在预告、MV、旅拍、动作蒙太奇或开场组接等需要高密度节奏的段落启用：

- 节奏驱动：先确定鼓点、停顿、段落变化和能量转折，再把画面动作节点对齐这些位置。
- 视觉驱动：先按动作、方向、形状、颜色或焦点建立画面链，再让声音强调已有的视觉节点。

验收快切时检查整体节奏方向、镜头之间的逻辑和目标观感。不要为追逐每个鼓点牺牲动作完整性、信息可读性或剧情因果。

## 8.1 动态强度按题材选择

高速环绕、人镜互相追逐、强风、前景高速掠过和多段变轨适合角色展示、玄幻力量或运动冲击，不是默认电影感。使用时让摄影机变化触发人物眼神、头部、肩膀和重心的连续响应，并保留头发、衣摆和饰品的惯性时间差。对白、群戏、地点展示和克制情绪优先使用稳定、可读、少而明确的运镜。

## 9. 常见失败诊断

| 症状 | 优先检查 | 修正方式 |
|---|---|---|
| 人物变脸/服装漂移 | 资产与引用职责 | 锁定角色资产，减少冲突描述，按镜头调用同一版本 |
| 场景像棚拍或塑料 | 环境关系与物理光 | 加前中后景、接触、生活痕迹、光源方向和衰减 |
| 动作僵硬 | 因果与状态流 | 补触发、重心、次级反应和结束状态 |
| 运镜混乱/乱切 | 路径与时间轴 | 写起点、轨迹、速度、节点和终点；复杂空间给调度图 |
| 多人站位错误 | 空间依据 | 使用俯视站位图、编号、方向和各自目标 |
| 产品形状变化 | 结构资产 | 使用多视角产品图、深度/法线/轮廓或局部标注 |
| 多段视频跳色 | 摄影与色彩基准 | 固定色卡、光线、焦段与质感，最后统一校色 |
| 颜色脏杂或像统一滤镜 | 色板功能与物理落点 | 绑定主色/阴影/光源/辅助/强调色的区域与材质，保护肤色和功能色 |
| 人物像贴在背景上 | 资产棚拍光被误继承 | 只锁定身份与材质，按场景物理光源重生人物光影、接触和遮挡阴影 |
| 情绪表演过度 | 指令过于直白 | 删掉同步表情堆叠，用克制反应和停顿表达 |
| 准确文字变形 | 生成模型重绘 | 保留原始静帧或后期叠字，并明确禁止重写 |

每次只修一个主要变量，并保留有效结果。局部问题优先局部修改、遮罩或条件图，不要把整段提示词推倒重来。

## 10. 负面约束与实验技巧

- 负面约束要短而具体，例如禁止新增人物、脸部漂移、塑料皮肤、无来源高光、过度锐化、文字重绘和无关切镜。
- “扰动词、误读、假因果、可控失控”等方法只用于有明确审美目标的实验镜头。一次改变一个关系或物理规则，其余元素保持可信，避免不可诊断的随机堆叠。
